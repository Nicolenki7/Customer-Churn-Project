Cómo se calcula

Una fila por cliente; cada corte agrupa por una sola dimensión.

  1. Cada fila es un cliente; la tasa es la media de Churn convertida a 0/1.
  2. Los tramos de antigüedad se cortan en 12, 24 y 48 meses, que son los saltos de contrato del dataset.
  3. No se cruzan dos dimensiones a la vez: cada gráfico responde una pregunta distinta.
  4. La cuota es MonthlyCharges, no el gasto histórico total.

Qué no dice este informe

Lo que este dataset no permite afirmar.

  • El CSV no trae fecha de baja ni motivo: no se puede saber cuándo se fue ni por qué.
  • Sin coste de adquisición no se puede calcular el valor de vida del cliente.
  • Es una foto de una operadora ficticia congelada en el tiempo, no una serie mensual.
  • Los grupos pequeños (dos meses de contrato) tienen tasas inestables.
